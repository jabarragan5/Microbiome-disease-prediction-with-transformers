The objective of the final project is to use microbial community sequencing data to train a machine learning model, specifically a transformer based sequence model to predict an individuals autoimmune disease risk. The aim is to treat microbiome composition as ordered sequence data and determine whether the patterns in microbial abundance can be learned by an attention based  model. More broadly, the goal is to explore and apply the tools covered in the course to evaluate how well microbiome derived features can classify autoimmune risk.
The baseline model I implemented was a lightweight transformer classifier designed to predict autoimmune disease risk from microbiome sequence data. The input was made up of sequences length 256 with 2 features per position. These positions represent abundance and location encoding. The model began with a projection dense layer that expanded the two dimensional features into a 32 dimensional embedding(d_model=32). This was followed by a single transformer encoder block containing a 2 head multi head attention layer (num_heads =2 with 32 dimensional outputs), a residual connection, layer normalization, and a fed forward network with a hidden size of 64 (ff_mult =2 x d_model). Dropout (0.1) was applied throughout to reduce overfitting. After the transformer block, the model used global average pooling to compress the sequence into a single vector, followed by a 64 unit Dense layer and a final sigmoid output for binary classification. In total, the baseline network contained approximately 10817 trainable parameters. The model learns patterns in microbial community structure by allowing each position in the sequence to reference to all others, capturing interactions between taxa that may be predictive of autoimmune disease.
In the first experiment, I built and trained a baseline transformer style neural network to assess whether a simple attention based model could learn patterns in the microbiome sequence embeddings and predict autoimmune disease risk. The baseline architecture accepted an input tensor of size 256x2, projected the features into a 32 dimensional space, and passed them through a single multi head attention layer with two heads.

This was followed by a feed forward network (64 to 32 units), global average pooling , and a sigmoid output layer. Trained over 40 epochs with a batch size of 256, the baseline model achieved an accuracy of approximately 0.73 and a AUC of around 0.81. This performance established a solid foundation and demonstrated that even a relatively small transformer could successfully identify biologically meaningful structure in the microbial distribution data.

The second experiment addressed the computational bottlenecks that emerged during baseline training, including slow epoch times and occasional stall caused by RAM limitations in the cloud environment. To solve this, I implemented a streamlined model that kept the overall transformer design but reduced the number of parameters. The simplified network used one attention block, a feed-forward multiplier of 2, dropout of 0.1, and retained a 32 dimensional latent space. This reduced the parameter count to 10817 and decreased epoch runtime from roughly six second to just over two seconds. Despite being smaller, the fast model maintained strong performance with an average AUC of 0.8056 and accuracy of 0.735 across seeds, demonstrating that the lighter architecture was both computationally efficient and still capable of meaningful predictive accuracy.

In the third experiment, I examined whether model performance was stable across different random seed or highly sensitive to initialization. Using the fast architecture, I trained two models with seeds 101 and 202 under identical training conditions and compared their validation metrics. Seed 101 produced an AUC of 0.7418. Averaged together, the model showed a mean AUC of 0.8056 and accuracy of 0.7352. These results indicated that the model's performance was robust across random initializations, with only minor variation, confirming the reliability of conclusions drawn from any single run.

The fourth experiment  explored wether increasing model depth would improve performance. I doubled the number of Transformer blocks, increasing the parameter count to 19,361. This deeper network was significantly slower, with epoch times ranging from six to thirty seconds depending on memory load. Despite the added capacity, the deeper architecture did not improve performance; instead it, produced a mean AUC of 0.791 and accuracy of 0.718 across seeds slightly worse than the simpler models. This experiment demonstrated that additional depth did not translate into better learning for this dataset and that larger architectures may overfit or struggle under constrained compute resources.

The fifth  experiment combined all prior insights to train an optimized small model designed to finish within computational limits while still achieving strong predictive performance. Training the fast model to approximately 20-25 epochs where both AUC and accuracy consistently plateaued yielded the best overall results. A representative run produced an accuracy of 0.7819, an AUC of 0.8643,a precision of 0.7927 and a recall of 0.7770, exceeding the performance of both the baseline and the deeper model. This experiment confirmed that the optimal configuration for this dataset was a compact Transformer architecture trained for a moderate number of epochs, and that increased complexity did not necessarily improve predictive capability. Overall, these analyses provided a systematic evaluation of architectural choices, computational trade offs, and performance stability, ultimately identifying a model that was efficient, reliable , and well suited to the dataset and the constrains of the computational environment.

In an additional experiment, I compared the transformer architecture to two alternative sequence modeling approaches: a 1D convolutional Neural Network and a long short term memory network. To make the comparison fair, I implemented a projection layer that mapped the input from 2 features to a 32 dimensional latent space, matching the internal representation of the transformer models. The ConV1D model consisted of a single 32 filter convolution (kernel size 3), followed by global average pooling a dense classifier. The LSTM model used a single LSTM layer with 32 hidden units followed by a dense output. Both models were trained using the same batch size, optimizer and number of epochs as the transformer baseline. The Conv1D model trained the fastest, with epoch times averaging 0.7-1.0 seconds, compared to 2-3 seconds for the fast  Transformer and 6-30 seconds for the deeper transformer. I also had the fewest parameters (~7000), reflecting its simplicity. Its validation performance reached an accuracy of approximately 0.70-0.72 and AUC values around 0.76-0.79 ,slightly below but still comparable to the Transformer. The LSTM model contained ~15000 parameters and was slower to train than Conv1D, averaging 1.5-2.0 seconds per epoch, but still faster than both transformer variants. The LSTM achieved accuracy values around 0.71-0.74 and an AUC between 0.79-0.82, performing closer to the baseline transformer but with noticeably higher variance between runs.  

This experiment demonstrated that while Conv1D and LSTM models can learn useful sequence structure from the microbiome embeddings, the transformer architecture consistently offered the best balance of accuracy, robustness, and representational power. Conv1D was the most computationally efficient but slightly less accurate, while LSTM showed competitive predictive performance but was more prone to overfitting, especially when trained for additional epochs. Overall, the transformer model provided the strongest and most stable results, validating its suitability for this classification problem while highlighting the trade offs associated with alternative sequence modeling approaches.
